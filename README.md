# System Resource Monitoring and Automated Performance Diagnostic Framework

An Operating Systems project that monitors system resources (CPU, memory,
disk, processes, threads, network, file descriptors), stores historical
data, and applies rule-based diagnostics to detect and explain abnormal
resource usage.

## Status
🚧 Under development — Phase 0 (project setup) complete.

## Tech Stack
- Python + psutil (monitoring)
- SQLite (storage)
- Streamlit + Plotly (dashboard)
- C++ (OS concept demonstrations: threads, sync, IPC, scheduling)
